# GitHub 一键发布助手 (github-publisher)

给 AI Agent 用的 Skill，一句话把本地生成的项目发布到 GitHub，自动建仓、自动传文件、自动写 README。

## 这是什么？

如果你用 AI Agent（比如豆包）写 Skill、写小工具，写完之后还得手动去 GitHub 建仓库、手动传文件、手动写 README，整个过程至少五六步，很麻烦。

装了这个 Skill 之后，你只要跟 AI 说一句"发布到 GitHub"，剩下的它全帮你搞定。

## 解决了什么问题？

- 之前：写完代码 → 打开 GitHub → 点 New Repository → 填名字 → 传文件 → 写 README → 提交，至少 5 分钟
- 现在：写完代码 → 说一句"发布到 GitHub" → 问你两个问题 → 完事，30 秒

## 核心功能

- **自动识别项目**：自动找到当前对话里最近生成的那个文件夹
- **一键建仓**：在你的 GitHub 账号下自动新建仓库
- **自动传文件**：递归读取文件夹里所有文件，一次性推上去
- **自动写 README**：根据项目内容自动生成一个像样的介绍，陌生人看完就知道这是什么、怎么用
- **安全可控**：发布前必须你确认仓库名和公开/私有，不会自作主张

## 怎么用？

### 前提

1. 你已经在豆包里授权了 GitHub 连接器（github-remote 插件）
2. 把这个 `github-publisher` 文件夹放到你的 `.user_skills` 目录里

### 触发方式

在任何一个对话里，写完一个项目之后，直接说：

> "发布到 GitHub"

或者：
> "把这个 skill 传到我的 GitHub 上"

### 它会做什么？

1. 自动找到当前目录下最近生成的文件夹
2. 问你：仓库叫什么？（默认用文件夹名）
3. 问你：公开还是私有？
4. 自动生成 README.md
5. 在 GitHub 建仓库、推文件
6. 把仓库链接给你

## 项目结构

```
github-publisher/
└── SKILL.md    # Skill 主文件，AI 读这个就知道怎么执行
```

就一个文件，很轻量。

## 适用场景

- 你用 AI 写了一个新的 Skill，想存到 GitHub 备份或者分享出去
- 你写了个小工具脚本，想快速传到 GitHub 上
- 你不想每次发布都手动点半天网页

## 注意

- 每个项目单独建一个仓库，不会混在一起
- 发布前一定会跟你确认仓库名和可见性，不会偷偷发出去
- 如果文件里有密码、API key 之类的敏感信息，它会提醒你
